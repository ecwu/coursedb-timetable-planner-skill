# CourseDB Timetable Planner Skill

当前版本为 2.11，与 CourseDB 项目的 `skills/plan-semester-courses` 同步。

本 Skill 读取 CourseDB 事实来规划学期课程。只有用户明确要求预览或导出时，才创建临时预览。它不修改个人 Planner，也不代替学校确认选课资格。

完整技能目录位于 [plan-semester-courses](plan-semester-courses/)。安装时保留整个目录及其 `references/` 和 `agents/` 文件。

[完整说明、安装方法与 MCP 配置](plan-semester-courses/README.md)。

本地维护时，以 CourseDB 项目的发布源码为同步来源，更新完整目录，避免只改版本号或 SKILL.md。
